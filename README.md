<h1 align="center">
  📚 Books Store (Full Stack)
</h1>

<br>

> 📖 **Books Store** is a full-stack e-commerce web application for browsing, searching, and purchasing books.  
Built for the first time as a **full-stack project**, combining **React (frontend)** and **Spring Boot (backend)** with a **PostgreSQL database**.

> 🚀 The app includes authentication, cart management, and real-time book search.

<br>

---

## ✨ Features

- 🔐 User Authentication (Login / Register)
- 📚 Browse list of books
- 🔍 Search books by title
- 🛒 Add / Remove / Manage shopping cart
- ➕ Increase / Decrease product quantity
- 👤 User dashboard with profile info
- 💾 Persistent cart (database + local state sync)
- ⚡ Fast UI updates with React Query
- 🔔 Toast notifications (React Hot Toast)
- 🎨 Modern responsive UI with Tailwind CSS
- 🔄 State management using Redux Toolkit

## 🚀 Getting Started 


### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/books-store.git
```

### 2️⃣cd backend

```
./mvnw spring-boot:run
```

### 3️⃣ cd frontend
```
npm install
```
```
npm run dev
```

### 4️⃣ Apps run on :

http://localhost:5173
